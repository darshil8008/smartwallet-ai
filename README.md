# SmartWallet AI

Hack Midwest 2026

## Project Overview
SmartWallet AI recommends the best credit card for
a purchase based on merchant category, cashback
rates, reward caps, and special conditions.

## Team
- Khevna — AI, AWS Strands Agents, FastAPI
- Smit — React Native, Expo, UI/UX
- Darshil — Akamai Cloud, Data, Deployment

## Technology Stack
- React Native + Expo + TypeScript
- Python + FastAPI
- AWS Strands Agents SDK
- Akamai Cloud and AI Inference
- JSON / SQLite

## Core Features
1. Merchant selection
2. Credit card rewards comparison
3. Spending cap calculation
4. Best-card recommendation
5. AI-powered explanations

## Project Structure
- mobile/ — Mobile application
- backend/ — FastAPI and AI agent
- data/ — Merchant and card datasets
- deployment/ — Cloud deployment
- scripts/ — Integration utilities
- tests/ — Automated tests
